# 综合素质测评审批系统

面向高校综合素质测评的全流程线上系统，覆盖**学生填报 → 班级复核 → 年级复核 → 资格认定 → 成绩核算 → 公示异议 → 材料归档**的完整链路。

原本依赖纸质材料收取与人工汇总的测评工作，可通过本系统在线完成。

> 本项目由一名临床医学专业本科生在 AI 智能体辅助下独立完成，未使用商业开发框架，后端为零脚手架的原生 Express 应用。

---

## 功能概览

### 四类角色

| 角色 | 权限范围 |
|---|---|
| 学生 | 提交申请、上传材料、查看审核状态与结果、公示期提出异议 |
| 班长（班级评议） | 审阅本班已认定类材料，认定或退回，退回须填写原因 |
| 年级负责人 | 二次审核，可改判班级结果、整份退回，管理未认定类材料 |
| 管理员 | 规则配置、用户管理、数据导出、日志审计、全程备案导出 |

### 核心能力

- **材料填报** —— 移动端拍照上传，按德育 / 智育 / 体育分类填写，必填项与附件完整性实时校验
- **多轮复核** —— 状态机驱动，支持认定、驳回、待补交、整份退回、学生主动撤回
- **智育自动计分** —— 按课程成绩与学分加权计算，整学年合并
- **防重复申报** —— 同一材料跨类别、跨榜单重复使用的检测与拦截
- **公示与异议** —— 四榜公示，异议走独立的处理流程
- **全程备案导出** —— 按专业 / 班级 / 学号分层，逐生生成 Word 文档并归档附件
- **操作留痕** —— 关键操作记录操作人、时间与内容，可回溯
- **附件访问控制** —— 附件不设静态目录直连，仅可通过带归属校验的接口读取

## 技术栈

| 层次 | 选型 |
|---|---|
| 运行时 | Node.js ≥ 16（推荐 20 / 22） |
| Web 框架 | Express 4 |
| 数据库 | better-sqlite3（WAL 模式，事务 + 防抖写入） |
| 前端 | 原生 JavaScript，无构建步骤 |
| 导出 | exceljs / docx / archiver |
| 附件识别 | tesseract.js（OCR） |
| 对象存储 | Cloudflare R2（可选，未配置时回退本地 zip） |
| 安全 | helmet / express-rate-limit / 敏感操作二次密码 |

**架构要点**

- 业务数据以 key-value 快照形式存储于单表 `store`，读取后在内存中操作，写入经 fastq 串行队列防并发覆盖
- 敏感字段（身份证号、手机号）加密存储，主密钥来自环境变量，缺失时进程拒绝启动
- 无前端构建链，`public/` 下即最终产物，部署时无需打包

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 准备环境变量
cp .env.example .env
# 生成主密钥并填入 ZONGCE_MASTER_KEY
openssl rand -hex 32

# 3. 启动
npm start
```

首次启动会自动建库并写入种子数据，访问 `http://localhost:3000` 即可。

详细配置见 [docs/配置说明.md](docs/配置说明.md)，生产部署见 [docs/部署说明.md](docs/部署说明.md)。

## 安全设计

| 措施 | 说明 |
|---|---|
| 主密钥 fail-fast | 缺失或长度不对时拒绝启动，避免以空密钥写库导致数据损坏 |
| 密码哈希 | 不可逆哈希存储，不保存明文 |
| 二级密码 | 改判、导出、清除等敏感操作需二次验证，与登录密码分离 |
| 限流 | 敏感接口按账号维度限流，避免共享出口 IP 互相影响 |
| 附件保护 | 无静态目录直连，下载与预览均校验归属 |
| 操作留痕 | 高风险操作写入审计日志 |
